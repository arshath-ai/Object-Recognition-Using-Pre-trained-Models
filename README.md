# Object Recognition Using Pre-trained Models

This project uses Python, OpenCV, and a pre-trained MobileNet SSD model to detect and recognize objects in real time using a webcam.

## Features
- Real-time object detection
- Detects multiple objects
- Displays object names and confidence scores
- Draws bounding boxes around detected objects

## Technologies Used
- Python
- OpenCV
- MobileNet SSD
- NumPy
- Imutils

## Installation

```bash
pip install opencv-python numpy imutils
```

## Run the Project

```bash
python main.py
```

**Note:** Make sure the MobileNet SSD model files are in the project folder. Press `ESC` to exit.
